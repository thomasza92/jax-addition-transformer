# 'How to Land a Frontier Lab Job' Transformer

Transformer written in JAX/Flax/Optax that learns addition over: 0-9, space, +, =.

## Setup

```
uv sync
```

## Inspiration

Created for the purposes of learning, inspired by [this blog post](https://vladfeinberg.com/2026/05/10/how-to-land-a-job-at-a-frontier-lab.html).
